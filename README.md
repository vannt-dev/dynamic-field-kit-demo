# dynamic-field-kit-demo

> **Archived.** The demos now live in [dynamic-field-kit](https://github.com/vannt-dev/dynamic-field-kit)
> itself, under `example/`, and are built from the same commit as the packages:
> [live demos](https://vannt-dev.github.io/dynamic-field-kit/). The apps in this repository use an
> early release of the kit (core 1.0, react 1.1) and are kept for reference only.

Demo apps for `Dynamic Field Kit` across multiple frameworks.

## Apps

- `react-app`: Next.js + React demo using `@dynamic-field-kit/react`
- `dynamic-demo-next`: another Next.js + React demo
- `dynamic-demo-vite`: Vite + React demo
- `vue-app`: Vue 3 + Vite demo using `@dynamic-field-kit/vue`
- `angular-app`: Angular demo using `@dynamic-field-kit/angular`

Each app renders a simple dynamic form and shows the current form state as JSON.

## Run

Install dependencies and run each app from its own folder.

React Next.js demo:

```bash
cd react-app
npm install
npm run dev
```

Next.js demo:

```bash
cd dynamic-demo-next
npm install
npm run dev
```

React Vite demo:

```bash
cd dynamic-demo-vite
npm install
npm run dev
```

Vue demo:

```bash
cd vue-app
npm install
npm run dev
```

Angular demo:

```bash
cd angular-app
npm install
npm start
```
